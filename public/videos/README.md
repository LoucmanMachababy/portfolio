# Vidéos de démonstration des projets

Ce dossier contient les vidéos de démonstration de vos projets.

## Fichiers attendus :

- `Demo_Neotech.mp4` - Démonstration de la plateforme Neotech E-commerce ✅
- `Demo_my_snapchat.mp4` - Démonstration de l'application My Snapchat ✅
- `Demy_MyQuizz.mp4` - Démonstration de l'application My Quizz ✅
- `kyol-poke-demo.mp4` - Démonstration de l'application Kyol Poke

## Format recommandé :

- **Format** : MP4
- **Résolution** : 1920x1080 (Full HD) ou 1280x720 (HD)
- **Durée** : 30-60 secondes par vidéo
- **Taille** : Maximum 10MB par vidéo pour un chargement optimal

## Conseils pour les vidéos :

1. **Démarrez par une vue d'ensemble** de l'interface
2. **Montrez les fonctionnalités principales** une par une
3. **Utilisez des transitions fluides** entre les sections
4. **Ajoutez des annotations** si nécessaire pour expliquer les fonctionnalités
5. **Terminez par un call-to-action** ou une vue finale

## Outils recommandés pour créer les vidéos :

- **Loom** - Enregistrement d'écran simple
- **OBS Studio** - Gratuit et professionnel
- **Camtasia** - Plus d'options d'édition
- **QuickTime** (Mac) - Enregistrement d'écran natif

Une fois vos vidéos prêtes, remplacez simplement les fichiers placeholder par vos vraies démonstrations !
